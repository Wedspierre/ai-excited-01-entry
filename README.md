# The Paper Plane That Outgrew the City

[![rank](https://make.fun/badge/ai-excited-01/Wedspierre/ai-excited-01-entry/rank.svg)](https://make.fun/bounty/ai-excited-01/leaderboard)
[![reward](https://make.fun/badge/ai-excited-01/Wedspierre/ai-excited-01-entry/reward.svg)](https://make.fun/bounty/ai-excited-01)

A paper plane the size of a city block glides between the skyscrapers at dusk,
close enough to touch the rooftops, while tiny people watch from below with
their arms in the air. The most ordinary toy in the world — folded from a
single sheet — grown impossibly large, catching the last light of the sunset
as it sails over the city that made it.

`main.ts` draws the whole scene procedurally (pixel renderer + hand-written
PNG encoder, Node 22 stdlib only, no network, fully deterministic) and writes
one image to `$MAKEFUN_OUTPUT_DIR/entry.png`.

Run it:

```sh
node main.ts
```
