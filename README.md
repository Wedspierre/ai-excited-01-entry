# Sunset Leap

A train leaps the gap of a broken bridge at sunset — launched off rails that
curl upward like a ski jump, locomotive nose-down toward the far deck, sparks
flying, smoke trailing, one wheel torn loose and tumbling into the gorge
below. The whole train is a black silhouette against a huge low sun, so the
moment reads in a single glance: impossible scale, real danger, full speed.

`main.ts` draws the image procedurally (pixel renderer + PNG encoder, Node 22
standard library only, fully deterministic) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.png`.
